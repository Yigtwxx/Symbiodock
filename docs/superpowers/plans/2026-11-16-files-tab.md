# Files Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third, always-present `Files` tab: drop files onto the island, drag them out elsewhere, convert them between formats behind a venom "engulf" effect, and show a round count bubble right of the notch.

**Architecture:** Pure logic (tab order, shelf, file kinds, conversion catalog, output naming, engulf geometry and timing) lives in `SymbiodockCore` and is test-driven. The app target adds AppKit drag-and-drop on the existing full-screen panel, a `ShelfCoordinator` that owns every shelf mutation and conversion, built-in macOS converters, and SwiftUI views that reuse `SymbioteCanvas`.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Swift Testing, PDFKit, AVFoundation, QuickLookThumbnailing (all system frameworks).

Spec: `docs/superpowers/specs/2026-11-16-files-tab-design.md`. Read it before any task.

**Catalog rules** (`ext` lowercased; a target whose extension family equals the source's is left out; families: jpg=jpeg, tif=tiff, heic=heif, aif=aiff, htm=html):
- A directory other than `rtfd`: `[ZIP]`.
- `zip`: `[Unzip]`.
- image → `PNG(png, sips "png")`, `JPEG(jpg, sips "jpeg")`, `HEIC(heic, sips "heic")`, `TIFF(tiff, sips "tiff")`, `GIF(gif, sips "gif")`, `BMP(bmp, sips "bmp")`, `PDF(pdf, sips "pdf")`.
- document → `PDF(pdf, printPDF)`, `DOCX`, `RTF`, `TXT`, `HTML`, `ODT` (textutil, format = lowercased label).
- `pdf` → `PNG(png, pdfPages(jpeg: false))`, `JPEG(jpg, pdfPages(jpeg: true))`, `TXT(txt, pdfText)`.
- audio (`mp3 m4a aac wav aif aiff flac caf` only) → `M4A(m4a, afconvert("m4af","aac",256000))`, `WAV(wav, ("WAVE","LEI16",nil))`, `AIFF(aiff, ("AIFF","BEI16",nil))`, `FLAC(flac, ("flac","flac",nil))`.
- video (`mov mp4 m4v` only) → `MP4(mp4, avExport(false,"mp4"))`, `MOV(mov, avExport(false,"mov"))`, `M4A(m4a, avExport(true,"m4a"))`.
- Every list except `zip`'s ends with `ZIP(zip, .zip)`. Anything else: `[ZIP]`.

**Commands:**
- sips: `/usr/bin/sips`, `["-s","format",f] + (f == "jpeg" || f == "heic" ? ["-s","formatOptions","90"] : []) + [source,"--out",output]`
- textutil: `/usr/bin/textutil`, `["-convert",f] + (sourceExtension == "md" ? ["-format","txt"] : []) + ["-output",output,source]`
- afconvert: `/usr/bin/afconvert`, `[source,"-o",output,"-f",file,"-d",data] + (bitrate.map { ["-b","\($0)"] } ?? [])`
- zip: `/usr/bin/ditto`, `["-c","-k","--sequesterRsrc","--keepParent",source,output]`
- unzip: `/usr/bin/ditto`, `["-x","-k",source,output]`

**State rules:**
- `addShelfItems`, `removeShelfItem`, `selectShelfItem`, `clearShelf`, `restoreShelf` work whatever the phase; assign `shelf` only on change.
- `setHovering` passes `filesHasContent: !shelf.isEmpty`.
- `setFileDragHovering(true)`: ignored unless collapsed or expanded; collapsed → `setHovering(true, opening: .files)`; expanded → `selectTab(.files)`. `false` only clears the flag.
- `revealConversion`: ignored unless that item is converting and not yet revealing. `.converted` replaces the item; `.failed(text)` sets `shelfNotice`; `.cancelled` neither. All set `revealStarted`.
- `beginConversion` clears a notice about that item. `endConversion` removes the entry.

At strand progress `q` (cubic ease-out of the phase progress after its delay) the ribbon reaches `q` of the way; its tip is a feeler (`max(0.6·neck, 0.8)`) with a bead droplet (`max(1.5·neck, 1.5)`), as in the notch's feelers.

At `p = 1`, and for `.cocoon`, the frame also holds the tile's rectangle grown by 2 pt as one ribbon: full cover is a fact, not a hope.
- Highlights: sheen slivers along the thicker strands (the shared sheen builder), and for `.cocoon` three fixed slivers and a rim line across the cover.
- `.reveal(p)` is not the engulf backwards: the cover first pinches along the middle (`1 − pinch·exp(−((s − mid)/9)²)`, as the bridge's tear), then each half-strand pulls back to its root with the stub's taper `(tip + (end − tip)·(1 − q)²)` and a bead at the tip; roots thin last. Empty at `p = 1`.
- `.engulf(0)` and `.done` are empty frames.

## Manual checklist (for the owner)

1. Hover the island: the tab strip shows three tabs; `Files` is third and opens an empty page saying `Drop files here`. `First tab` in the right-click menu lists only `Agents` and `Media`.
2. Drag a file from a Finder window to the notch: the island opens on `Files` before you let go, shows a dashed frame, and the file becomes a tile when dropped. A light tick is felt.
3. Drop a folder, a photo and several files at once: one tile each, newest first. Drop the same file again: no duplicate, it moves to the front.
4. Drag an image out of Safari onto the island: it becomes a tile.
5. Move the pointer away: the island closes and a round bubble right of the notch shows the count in the colour of the newest file's kind; with other kinds held, up to two smaller discs show behind it on the right.
6. Rest on the bubble: the island opens on `Files`.
7. Swipe to a full-screen app, open the island, drag a tile into that app (a Finder window, a Mail message, a chat): the file arrives and the tile leaves the shelf.
8. Start dragging a tile and press Escape, or drop it on the Desktop wallpaper of a full-screen video: the tile stays.
9. Press on empty space of the Files page and drag: the island tears off as before. Press on a tile and drag: only the file moves.
10. Select an image and press `JPEG`: goo closes over the tile, holds, opens; the tile now reads `JPG` and `name.jpg` lies beside the original in Finder, the original still there.
11. The same for a DOCX → `PDF`, an audio file → `M4A`, a short video → `MP4`, a folder → `ZIP`, that ZIP → `Unzip`, a multi-page PDF → `PNG` (a `name pages` folder).
12. Start a long video conversion and press `Cancel`: the tile opens unchanged and no stray file is left in the folder.
13. Convert a file that sits in a read-only place (a mounted disk image): the tile opens unchanged and says `Can't write to this folder`.
14. Quit Symbiodock and open it again: the shelf is as you left it. Rename one of the files in Finder first: it is still there under its new name. Delete one: it is gone from the shelf.
15. `Remove` (×) takes a tile off without touching the file; `Clear Files` in the right-click menu empties the shelf.
16. Dock the island to a side or the bottom: the Files page works there; there is no files bubble.
17. Turn on Reduce Motion: converting darkens and lightens the tile without goo; the bubble fades in.
18. With files held and nothing else going on, `top -pid $(pgrep -x Symbiodock)` shows Symbiodock at 0 %.
19. Note whether the bubble covers a menu bar icon you use; whether dragging in ever fails to open the island; whether the DOCX → PDF layout is acceptable.
20. Select three files in Finder and drop them together: one drawer, the first file in front, the others showing their top edges behind it, a `3` on the front card.
21. Move the pointer over a back file's edge: it rises a little and the name under the drawer becomes that file's. Over the top edge of the front card: only the front card rises.
22. Click a back edge: that file comes to the front and is the only one selected. Click the drawer's body: the whole drawer is selected and the column says `3 files`.
23. ⌘-click another tile: it joins the selection; ⌘-click it again: it leaves.
24. Drag a file from Finder onto an existing tile: the tile gets a dashed frame and the file joins it as a drawer. Drag one shelf tile onto another: the same.
25. Drag a file by its edge out of a drawer onto the empty part of the row: it becomes a tile of its own. The `Unstack` icon in the column spreads a whole drawer.
26. Drag a drawer by its body into Finder: all its files arrive. Drag by a back edge, or by the front card's top edge: only that file goes.
27. Put two DOCX and one PPTX in a drawer, select it, press `PDF`: the whole drawer is swallowed, opens with two PDFs and the PPTX unchanged, and the column says `Slides.pptx can't become PDF`.
28. Select several files and press `ZIP`: one `Archive.zip` appears beside the first file and takes their place on the shelf.
29. Quit and reopen: drawers are still drawers.
