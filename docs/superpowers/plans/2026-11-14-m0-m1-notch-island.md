# Milestones 0–1: Project Skeleton and Notch Island — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An agent app that sits on the MacBook notch, expands on hover with placeholder content, collapses when the pointer leaves, and lets every click outside the island through.

**Architecture:** Pure geometry and state live in a local Swift package, `SymbiodockCore`, tested with `swift test`. The app target holds AppKit and SwiftUI code only: a full-screen transparent `NSPanel`, a SwiftUI island view, and a mouse tracker that toggles click-through. The Xcode project is generated from `project.yml` with XcodeGen and is not committed.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Swift Testing, XcodeGen 2.45+, Xcode (any version that supports a macOS 14 deployment target).

**Spec:** `docs/superpowers/specs/2026-11-14-symbiodock-v1-design.md`

## Global Constraints

- Minimum macOS: 14.0. Swift language version: 6.
- Agent app: `LSUIElement = true`. No Dock icon, no main window.
- Sandbox off. No entitlements file.
- Bundle identifier: `com.yigtwxx.Symbiodock`. Ad-hoc signing (`CODE_SIGN_IDENTITY = "-"`).
- The name is spelled `Symbiodock` everywhere.
- All code, identifiers and comments in English.
- `SymbiodockCore` must not import AppKit or SwiftUI.
- All island geometry is in panel-local coordinates: origin at the top-left of the display, y grows downward, units are points.
- Hover timing: expand after 80 ms inside the hit rect, collapse after 250 ms outside.
- Expanded island: 360 × 150 pt. Hit rect: island frame grown by 4 pt on every side.
- Virtual notch on displays without one: 200 × 32 pt, centered on the top edge.
- Commits: Conventional Commits, title ≤ 72 characters, imperative. After each task, commit and push directly to `main`. No pull requests.
- Never commit secrets, `.env` files or the generated `Symbiodock.xcodeproj`.

## Deferred to later plans (not in this plan)

- "Return to notch" menu entry, anchors other than the notch, dragging: milestone 3.
- Collapsed wings with artwork and level bars, real track data: milestone 2.
- Symbiote effect: milestone 4.

```swift
import CoreGraphics

/// The facts about a display that the island needs, as plain values.
public struct ScreenMetrics: Equatable, Sendable {
    /// Display frame in AppKit global coordinates (origin bottom-left, y up).
    public var frame: CGRect
    /// Height of the top safe-area inset; greater than zero on notch displays.
    public var safeAreaTop: CGFloat
    /// Width of the usable area left of the notch, nil without a notch.
    public var auxiliaryTopLeftWidth: CGFloat?
    /// Width of the usable area right of the notch, nil without a notch.
    public var auxiliaryTopRightWidth: CGFloat?

    public init(
        frame: CGRect,
        safeAreaTop: CGFloat,
        auxiliaryTopLeftWidth: CGFloat?,
        auxiliaryTopRightWidth: CGFloat?
    ) {
        self.frame = frame
        self.safeAreaTop = safeAreaTop
        self.auxiliaryTopLeftWidth = auxiliaryTopLeftWidth
        self.auxiliaryTopRightWidth = auxiliaryTopRightWidth
    }

    public var hasNotch: Bool {
        safeAreaTop > 0 && auxiliaryTopLeftWidth != nil && auxiliaryTopRightWidth != nil
    }

    /// Converts an AppKit global point to panel-local coordinates
    /// (origin top-left of this display, y down).
    public func localPoint(fromGlobal point: CGPoint) -> CGPoint {
        CGPoint(x: point.x - frame.minX, y: frame.maxY - point.y)
    }
}
```

`Packages/SymbiodockCore/Sources/SymbiodockCore/NotchGeometry.swift`:

```swift
import CoreGraphics

public enum NotchGeometry {
    /// Size of the stand-in notch on displays that do not have one.
    public static let virtualNotchSize = CGSize(width: 200, height: 32)

    /// The notch rect in panel-local coordinates.
    public static func notchRect(for metrics: ScreenMetrics) -> CGRect {
        if metrics.hasNotch,
           let left = metrics.auxiliaryTopLeftWidth,
           let right = metrics.auxiliaryTopRightWidth {
            return CGRect(
                x: left,
                y: 0,
                width: metrics.frame.width - left - right,
                height: metrics.safeAreaTop)
        }
        return CGRect(
            x: (metrics.frame.width - virtualNotchSize.width) / 2,
            y: 0,
            width: virtualNotchSize.width,
            height: virtualNotchSize.height)
    }
}
```

`Packages/SymbiodockCore/Sources/SymbiodockCore/IslandState.swift`:

```swift
import Observation

public enum IslandPhase: Equatable, Sendable {
    case collapsed
    case expanded
}

/// How long the pointer must stay inside or outside before the island reacts.
public enum HoverTiming {
    public static let enterDelay: Duration = .milliseconds(80)
    public static let exitDelay: Duration = .milliseconds(250)
}

/// The single source of truth for what the island is doing.
@MainActor
@Observable
public final class IslandState {
    public private(set) var phase: IslandPhase = .collapsed

    public init() {}

    /// Called after the hover delay has elapsed, not on every pointer move.
    public func setHovering(_ hovering: Bool) {
        phase = hovering ? .expanded : .collapsed
    }
}
```

`Packages/SymbiodockCore/Sources/SymbiodockCore/IslandLayout.swift`:

```swift
import CoreGraphics

/// Island frames in panel-local coordinates.
public enum IslandLayout {
    public static let expandedSize = CGSize(width: 360, height: 150)
    public static let hitPadding: CGFloat = 4

    public static func frame(phase: IslandPhase, notch: CGRect, screenSize: CGSize) -> CGRect {
        switch phase {
        case .collapsed:
            return notch
        case .expanded:
            let width = max(expandedSize.width, notch.width)
            let height = max(expandedSize.height, notch.height)
            let maxX = max(screenSize.width - width, 0)
            let x = min(max(notch.midX - width / 2, 0), maxX)
            return CGRect(x: x, y: 0, width: width, height: height)
        }
    }

    /// The area in which the pointer counts as hovering the island.
    public static func hitRect(phase: IslandPhase, notch: CGRect, screenSize: CGSize) -> CGRect {
        frame(phase: phase, notch: notch, screenSize: screenSize)
            .insetBy(dx: -hitPadding, dy: -hitPadding)
    }
}
```

```swift
import AppKit

/// Reports the pointer location in AppKit global coordinates.
///
/// The overlay panel ignores mouse events almost everywhere, so tracking areas
/// cannot be used; the pointer has to be observed from outside the window.
@MainActor
final class MouseTracker {
    enum Mode {
        /// Global and local NSEvent monitors. No work while the pointer is still.
        case eventMonitors
        /// Reads the pointer location 30 times per second. Needs no event access.
        case polling
    }

    private let mode: Mode
    private let onMove: @MainActor (CGPoint) -> Void
    private var monitors: [Any] = []
    private var timer: Timer?
    /// Fallback timer used only while the pointer is on the island (`.eventMonitors` mode).
    private var supplementalTimer: Timer?

    init(mode: Mode, onMove: @escaping @MainActor (CGPoint) -> Void) {
        self.mode = mode
        self.onMove = onMove
    }

    func start() {
        switch mode {
        case .eventMonitors:
            let mask: NSEvent.EventTypeMask = [.mouseMoved, .leftMouseDragged]
            if let global = NSEvent.addGlobalMonitorForEvents(matching: mask, handler: { [weak self] _ in
                MainActor.assumeIsolated { self?.report() }
            }) {
                monitors.append(global)
            }
            // Clicks also re-evaluate the pointer, so a lost exit event cannot outlive a click.
            let localMask = mask.union([.leftMouseDown, .rightMouseDown, .otherMouseDown])
            if let local = NSEvent.addLocalMonitorForEvents(matching: localMask, handler: { [weak self] event in
                MainActor.assumeIsolated { self?.report() }
                return event
            }) {
                monitors.append(local)
            }
        case .polling:
            timer = makePollingTimer()
        }
        report()
    }

    func stop() {
        monitors.forEach(NSEvent.removeMonitor)
        monitors.removeAll()
        timer?.invalidate()
        timer = nil
        setSupplementalPolling(false)
    }

    /// Turns the 30 Hz fallback polling on or off. Needed because once the panel accepts
    /// mouse events, the global monitor stops seeing them and local delivery is not guaranteed.
    /// No-op in `.polling` mode, where the timer always runs.
    func setSupplementalPolling(_ enabled: Bool) {
        guard mode == .eventMonitors else { return }
        if enabled {
            guard supplementalTimer == nil else { return }
            supplementalTimer = makePollingTimer()
        } else {
            supplementalTimer?.invalidate()
            supplementalTimer = nil
        }
    }

    /// `.common` mode keeps the timer firing while a menu is open (event tracking mode).
    private func makePollingTimer() -> Timer {
        let timer = Timer(timeInterval: 1.0 / 30.0, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.report() }
        }
        RunLoop.main.add(timer, forMode: .common)
        return timer
    }

    private func report() {
        onMove(NSEvent.mouseLocation)
    }
}
```

```swift
import AppKit
import SwiftUI
import SymbiodockCore

/// Owns the overlay panel, keeps it matched to the island's display,
/// and turns pointer movement into hover state and click-through.
@MainActor
final class OverlayController {
    /// Switch to `.polling` if event monitors do not deliver pointer movement.
    private static let trackerMode: MouseTracker.Mode = .eventMonitors

    private let state = IslandState()
    private var panel: OverlayPanel?
    private var metrics: ScreenMetrics?
    private var notch: CGRect = .zero
    private var screenObserver: NSObjectProtocol?
    private var tracker: MouseTracker?
    private var pointerInside = false
    private var hoverTask: Task<Void, Never>?

    func start() {
        // The tracker must exist before the first rebuild: if the pointer is already on
        // the island at launch, the rebuild turns on the tracker's safety-net polling.
        let tracker = MouseTracker(mode: Self.trackerMode) { [weak self] point in
            self?.pointerMoved(toGlobal: point)
        }
        tracker.start()
        self.tracker = tracker

        rebuildPanel()
        screenObserver = NotificationCenter.default.addObserver(
            forName: NSApplication.didChangeScreenParametersNotification,
            object: nil,
            queue: .main
        ) { [weak self] _ in
            MainActor.assumeIsolated { self?.rebuildPanel() }
        }
    }

    /// Recreates the panel for the current display configuration.
    private func rebuildPanel() {
        guard let screen = NSScreen.islandScreen else {
            resetHoverState()
            panel?.close()
            panel = nil
            metrics = nil
            notch = .zero
            return
        }
        let metrics = ScreenMetrics(screen: screen)
        // Nothing changed (e.g. unrelated screen-parameter notification): keep the panel.
        if panel != nil, metrics == self.metrics { return }

        resetHoverState()
        panel?.close()
        panel = nil

        let notch = NotchGeometry.notchRect(for: metrics)
        self.metrics = metrics
        self.notch = notch

        let panel = OverlayPanel(screenFrame: metrics.frame)
        let hostingView = NSHostingView(rootView: IslandView(state: state, notch: notch))
        // Keep SwiftUI from resizing the panel to the content's ideal size.
        hostingView.sizingOptions = []
        panel.contentView = hostingView
        panel.setFrame(metrics.frame, display: true)
        panel.orderFrontRegardless()
        self.panel = panel

        // The new panel ignores mouse events; re-check in case the pointer is already on the island.
        pointerMoved(toGlobal: NSEvent.mouseLocation)
    }

    /// Drops pending hover work and collapses the island so no stale state survives a rebuild.
    private func resetHoverState() {
        hoverTask?.cancel()
        hoverTask = nil
        state.setHovering(false)
        pointerInside = false
        tracker?.setSupplementalPolling(false)
    }

    private func pointerMoved(toGlobal point: CGPoint) {
        guard let metrics, let panel else { return }

        let hitRect = IslandLayout.hitRect(
            phase: state.phase, notch: notch, screenSize: metrics.frame.size)
        let inside = hitRect.contains(metrics.localPoint(fromGlobal: point))

        // Clicks reach the panel only while the pointer is on the island. Assign only on
        // change: this runs on every mouse move system-wide. While the panel accepts events
        // the global monitor is blind, so poll as a safety net against a lost exit event.
        if panel.ignoresMouseEvents == inside {
            panel.ignoresMouseEvents = !inside
            tracker?.setSupplementalPolling(inside)
        }

        guard inside != pointerInside else { return }
        pointerInside = inside

        hoverTask?.cancel()
        hoverTask = Task { [weak self] in
            try? await Task.sleep(for: inside ? HoverTiming.enterDelay : HoverTiming.exitDelay)
            guard !Task.isCancelled, let self else { return }
            self.state.setHovering(inside)
            // The hit rect depends on the phase; re-check. This only schedules new work
            // when the pointer really crossed the (now different) rect edge.
            self.pointerMoved(toGlobal: NSEvent.mouseLocation)
        }
    }
}
```
