# Symbiodock

A living notch for your MacBook. Symbiodock turns the notch into an island that
expands on hover, shows what you are playing, and can be pulled away from the
notch with a symbiote-like stretch effect to dock on any screen edge or corner.

## Status

Early development. Nothing is runnable yet.

## Planned for the first version

- Notch island that expands on hover
- Now Playing: track info and playback controls
- Drag the island off the notch with a stretching, tearing "symbiote" effect
- Snap to any screen edge or corner

## Tech

- Swift / SwiftUI + AppKit
- macOS 14 or later
